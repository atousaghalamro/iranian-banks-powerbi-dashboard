
# Iranian Banks – Power BI Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze the financial position and performance of Iranian banks.

The dashboard provides insights into banking assets, loans, and changes in financial indicators across different reporting periods.

## Dashboard Pages

### 1. Overview
A comprehensive overview of banking assets and loans, including key performance indicators.

### 2. Assets Analysis
Analysis of banks' book value, current asset valuation, asset usage, and acquisition methods.

### 3. Loans Analysis
Analysis of net loans, loan growth rates, changes in bank rankings, and comparisons across reporting periods.

### 4. Bank Profile
A dynamic profile of each bank, presenting its financial indicators and relative position.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Features
- Interactive dashboards and filters
- Dynamic KPIs
- Period-over-period comparisons
- Bank ranking analysis
- Financial performance visualization
